# Vue Tailwind Datepicker is becoming CodeRocket UI

Vue Tailwind Datepicker started with a focused problem: make dates easier to work with in a Vue application. Thank you to everyone who used it, reported an issue or contributed.

The next step is **CodeRocket UI**: tools to make a component library look like your product, keep its rules consistent, and share those rules with coding agents. You can [try the demo](https://ui.coderocket.app/#live-preview) or [read the documentation](https://ui.coderocket.app/docs).

The repository keeps its existing stars, issues and history. Its active code is now the React components, blocks, design-system engine, specifications, CLI and read-only MCP client. That foundation is open source under MIT. The hosted editor, accounts and AI service are maintained separately.

## What changes for datepicker users?

The Vue datepicker is **frozen and no longer maintained**. Its npm package, `@coderocketapp/vue-tailwind-datepicker`, stays available. Its MIT source and original attribution are preserved in [`legacy/vue-tailwind-datepicker`](legacy/vue-tailwind-datepicker), and [its documentation](https://vue-tailwind-datepicker.com) stays online.

No automatic migration or package rename is required in your applications. CodeRocket UI is a different product, initially for React. It is not a replacement Vue datepicker API, and there is no promised date for Vue support in the new library.

No new fixes, feature work or package releases are planned for the legacy component. If you need ongoing maintenance, the MIT source remains available for you to adapt or fork.

## Why this direction?

Generating another isolated component is easy. Keeping the same design rules across a real application takes care. CodeRocket UI gives you editable source, shared tokens and specifications that both developers and coding agents can use. The CLI preserves local edits; MCP reads the same saved library instead of inventing a different one.

The current components are experimental. The Studio is free during early access, and no paid subscription is enabled today. We want to learn from real integrations before promising a broader product.

If you would like to try CodeRocket UI on a project or discuss a pilot, [contact us](https://ui.coderocket.app/contact). This is an invitation to opt in: we will not automatically contact people who starred or used the datepicker.
